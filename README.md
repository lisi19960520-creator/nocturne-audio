# 静夜 · 音源库 v1

本仓库是「静夜」白噪音 App 的音频资源分发点。

全部录音来自 [opengameart.org](https://opengameart.org)，许可为 CC0 或 CC-BY。
音频已做无缝循环处理与响度统一（环境音 -22 LUFS），并转码为 44.1kHz 立体声 Vorbis。

App 通过 Release 资产直链按需下载，不在安装包内分发。
